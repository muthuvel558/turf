# PrimeTurf Arena - Online Turf Booking Platform

PrimeTurf Arena is a real-time online booking web application built with **React**, **Vite**, and **React Router**.

## 🚀 Features

- **Real-Time Slot Finder**: Select sport, date, duration (60, 90, 120 mins), and view live availability.
- **Dynamic Pricing**: Automatic pricing calculation (Off-Peak, Regular, Peak).
- **Smooth Booking Flow**: Step-by-step reservation process with instant confirmation.
- **Owner Dashboard**: Manage bookings, pricing, amenities, and facility details.

## 🛠️ Development

Run the development server locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
